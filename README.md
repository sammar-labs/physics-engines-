# ⚙️ Physics Engines & 3D Simulations

Welcome to my **Physics Engines & 3D Simulations** repository! This repository is dedicated to building custom physics engines, real-time simulations, and 3D graphics experiments from scratch using **Python**, **C++**, **NumPy**, and **OpenGL**.

---

## 🎯 Purpose & Vision

The goal of this repository is to explore and implement the core mathematics, algorithms, and rendering pipelines behind modern physics engines and computer graphics—without relying on pre-built game engines. 

Key areas of focus include:
* **Classical Mechanics & Kinematics:** Rigid body dynamics, gravity, projectile motion, and collision detection/response.
* **Numerical Computation:** High-speed vector and matrix operations using NumPy and C++.
* **3D Graphics & Rendering:** Real-time hardware-accelerated rendering, transformations, and custom shaders using OpenGL.
* **Cross-Language Performance:** Prototyping physics concepts in Python and optimizing heavy computations in C++.
